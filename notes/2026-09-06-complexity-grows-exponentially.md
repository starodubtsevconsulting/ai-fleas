# Complexity Grows Exponentially

**September 6, 2026**

Today's reminder: complexity grows exponentially.

One more command, one more integration, one more platform, one more installation mode — each addition does not merely
add its own complexity. It creates new relationships with everything already there.

That is probably a basic rule of working with software projects. It does not matter whether the software is written by
people, with AI, or by AI. The tools may change the speed of creation, but they do not repeal the growth of complexity.

It is worth remembering while deciding what to add, what to connect, and what to keep separate.

> Complexity grows exponentially.
>
> — Many generations before us; no single author
