# Keep Awake macOS preview packaging

This standalone Apple Silicon preview includes the installed Electron 44.3.0 macOS runtime, production Angular output and the command-owned main/controller/preload. The recipient needs no repository, Node.js or npm. The current runtime is arm64 only and declares macOS 13.0 or later. No Intel or universal build is supplied.

The parent runner owns installation, builds, tests, native UI checks and release execution. From this command directory, after the pinned launcher dependencies and Electron vendor binary are installed:

```sh
cd launcher
npm ci
npm run build
npm test
cd ..
node package-preview.cjs --unsigned-preview
```

Packaging itself is offline and installs nothing. It rejects development builds with source maps, requires extracted renderer licenses and the exact runtime/version/architecture/minimum-OS contract. It copies the runtime's complete bundle, keeps nested framework/helper/executable names intact, changes only the outer product metadata (bundle ID `consulting.starodubtsev.keepawake`), and installs the app payload in `Contents/Resources/app`. The application MIT license, Electron and Chromium notices and Angular third-party licenses travel inside the app. The MIT grant permits commercial distribution while preserving its notice.

Output is `output/release/Keep-Awake-VERSION-macOS-arm64-unsigned-preview/`: `Keep Awake.app`, its ZIP, `README.txt`, `release.json` and `SHA256SUMS`. This directory is ignored. An existing release directory is never overwritten or removed; review it before choosing a new package version or deliberately clearing a failed run. The script has no cleanup effect outside its own freshly created release directory.

The script uses ad-hoc signing solely for bundle integrity, verifies that signature, normalizes bundle timestamps using `SOURCE_DATE_EPOCH` (default 2024-01-01 UTC), and creates a sorted ZIP with preserved symlinks and without extended file attributes. Exact pinned inputs, the same macOS signing/ZIP tools and the same epoch provide the reproducible recipe; release hashes record the resulting artifacts. Reproduction across different macOS tool versions is not promised. Packaging does not establish application or sleep-behavior acceptance.

This is an unsigned distribution preview: ad-hoc signing provides no verified developer identity and no notarization. Downloaded copies may be blocked by Gatekeeper. Do not sell or present this draft as a normally installable notarized release. No quarantine removal or Gatekeeper bypass is part of this workflow.

Before a paid public release, separately configure a valid Developer ID Application identity and an explicit Keychain `notarytool` profile. A later release pipeline must replace preview signing with inside-out signing of Electron's nested code and the outer app, review required Electron hardened-runtime entitlements, enable hardened runtime and secure timestamps, verify the Developer ID/team, submit the ZIP using that explicit notary profile with bounded status polling, inspect accepted notarization, staple and validate the app, recreate the final ZIP and checksums, and test a genuinely downloaded quarantined copy on a supported clean Mac. No identity or notary profile is currently assumed; this preview script intentionally provides no public-release mode.

Parent acceptance: verify ZIP/checksums and contained architecture, copy the app outside the checkout and launch it without repository dependencies, inspect bundled notices, confirm the native Start confirmation, Awake/Stop behavior and child cleanup on quit/close. The separate supervised idle observation remains required for any extended awake claim. Manual lock, lid closure and managed policy remain outside the guarantee. Pricing/checkout/download fulfillment belongs to the product/storefront work, not this packaging script.

Packaged previews use their own persistent `Keep Awake Preview` user-data directory. The source launcher retains `AI Fleas Keep Awake`. The selector uses the exact `keep-awake` package name generated by this packager, rather than `app.isPackaged`: Electron 44.3.0 determines that flag from the executable basename and our preserved `Electron` executable makes it false. Version 0.0.3 corrects that source/preview single-instance collision; prior generated artifacts remain preserved and must not be distributed as the corrected build.

Parent-run 0.0.3 acceptance on 2026-10-11 passed packaging, strict bundle-signature verification, ZIP integrity and nine controller tests. Native launch opened Inactive from the bundled resources. Cancel in the Start warning stayed Inactive; confirmed Start showed Awake and `pmset` verified owned assertions for the packaged app’s caffeinate child. Stop returned Inactive. After a confirmed restart, closing the active window exited the app and its child. The original source app and its caffeinate session remained running. This verifies local lifecycle behavior, not a 20-minute idle observation or a clean quarantined-Mac installation; both remain unrun.

Verified 0.0.3 unsigned-preview ZIP: 128605596 bytes; SHA-256 `1cfb9774760ef1707c190bb26b241a0272f8db2bb4aa8d269586814cfac7b9d2`. Ad-hoc integrity signing remains distinct from Developer ID signing and notarization.
