# LinkedIn Article draft

1. Resolve canonical article/revision/assets and verify the signed-in LinkedIn profile against configured `account_profile_url`.
2. Open LinkedIn's Article editor for the intended author/profile. Reuse the intended draft when possible; avoid duplicates.
3. Transfer title/body/links/emphasis/headings/lists/quotes/code using current native editor controls. Treat the canonical article as source; verify the rendered result rather than trusting paste/import.
4. Apply the canonical Writing header-image contract. Upload the accepted lead image and verify crop/rendering. Convert unsupported diagrams/assets to verified LinkedIn-supported representations while preserving source/provenance.
5. Inspect beginning, middle, end, every visual/special block, links and spacing in the actual Article representation. Record intentional destination differences.
6. Return draft identity/URL or other stable browser evidence, state and unresolved issues to the archive. Stop unpublished. Never press Publish from this skill.

Use live browser semantics; LinkedIn UI may change. Missing account match, editor access, asset rendering or stable draft evidence is a blocker, not permission to publish as recovery.
