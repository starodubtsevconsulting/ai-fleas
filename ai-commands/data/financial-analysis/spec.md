# financial-analysis Spec

## Rules

- Calculations consume structured authorized evidence rather than arbitrary private storage.
- Keep observed facts, derived calculations, assumptions, and scenarios distinct.
- Preserve currency and period boundaries.
- Never silently invent exchange rates, missing transactions, future revenue, or obligations.
- Anomaly output is evidence for review, not accusation or diagnosis.
- Scenario output informs Financial Analyst/Personal Governor; it does not make the human's decision.
