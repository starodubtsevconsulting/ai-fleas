# Admin-delegated release approval

An author may explicitly appoint the initialized Writing Admin to make the release decision for an exact article and destination. This is an alternative decision path when the author does not plan to listen or review personally. It is not evidence that the author listened.

Admin records a durable `release-delegation` receipt under `.agent-runtime/writing/delegations/`. The receipt names the direct human instruction, authorizing task, profile and workflow, article revision, saved destination, allowed action (`schedule` or another exact action), publication target, and any limits. A broad standing instruction does not silently cover another article or immediate publication. Admin checks the final article, selected visuals, source claims, destination rendering, and archived narration script/audio as the author's representative. Admin records its own verdict and remaining defects. It never writes `human-listen` evidence or says the author listened.

For a new run, Writer preserves the exact human-authorized `work-request` in its review packet and result. Reviewer completes its independent article, destination, audio, and three-surface checks first. If they pass and the request delegates this exact release decision, Reviewer returns `admin_decision_required` with `review`, `destination-review`, and `work-request`. The Router assigns `admin_release_review` to Admin. Admin inspects those exact records and final surfaces, writes its revision-bound receipt, and returns `approved` with `review`, `destination-review`, and `release-delegation`; defects return `changes_required` to Writer, and an absent or out-of-scope mandate returns `decision_missing` to the human wait. Admin cannot approve an unreviewed or changed revision. For a late direct delegation, Admin returns `review-required` from `administration` with `revision`, `review-packet`, and `work-request` so Reviewer repeats the independent check through the declared route.

For an existing run already at `human_review`, Reviewer independently verifies the receipt's origin and exact scope, the final review and destination evidence, the three-surface mirror, and Admin's recorded verdict. If anything is stale or unresolved, return Writer-owned `changes_required` or a precise human/action blocker. If all checks pass, return `admin_delegated` with the exact `review`, `destination-review`, and `release-delegation` references. Both routes substitute a delegated release decision for the author's listen-through confirmation; neither proves playback.

Release Coordinator accepts `admin_release_review/approved` or `human_review/admin_delegated` only for the exact revision, destination, action, and target in the verified receipt. It records the release as **Admin-delegated; author listening unconfirmed**. A material change after the receipt requires a new Admin verdict and independent review. The narration remains in the permanent article archive and outside Git.
