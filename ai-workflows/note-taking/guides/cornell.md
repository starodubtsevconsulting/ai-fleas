# Cornell guide

Use a main note area, cues or questions, and a concise summary to support learning and review.

- Record the main material during capture or learning.
- Derive cues, questions, or key concepts after capture.
- Summarize the material concisely in your own words.
- Review by recalling from the cues instead of only rereading.
- Refine the notes when review exposes gaps.

Typical flow: `capture main notes -> derive cues -> summarize -> recall -> refine gaps`.

The exact page or template representation is an implementation choice.
