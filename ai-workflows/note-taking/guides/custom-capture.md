# Custom-capture guide

Use this extension point when reducing friction at capture time matters more than immediately applying a complete
structure.

- Capture quickly enough that useful information is not lost.
- Preserve original content and sources before transformation.
- Apply only the minimum metadata needed during capture.
- Defer classification, linking, summarization, or promotion until useful.
- Keep user-owned notes authoritative and generated metadata replaceable.
- Evolve conventions from actual retrieval and use.

Typical flow: `capture -> preserve source -> add minimal metadata -> process later -> retrieve or use`.

Personal syntax, paths, filenames, tags, applications, shortcuts, and processing rules belong in the selected profile,
not in this public guide.
