# Zettelkasten guide

Develop knowledge through focused, independently understandable notes connected by meaningful relationships.

- Capture ideas in your own words when possible.
- Prefer focused notes that can stand independently.
- Preserve source information where relevant.
- Link notes for meaningful conceptual relationships, not merely a shared label.
- Allow structure to emerge instead of requiring a complete taxonomy upfront.
- Revisit and refine notes as understanding develops.
- Use connections to support discovery, arguments, and writing.

Typical flow: `capture source -> understand -> create focused note -> connect -> revisit -> develop new work`.

Identifiers, filenames, links, indexes, and storage conventions belong in the selected profile.
