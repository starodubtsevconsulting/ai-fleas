# Financial Insights data ownership

Financial records belong to the human-owned profile, not this reusable workflow.
The public fictional example is at
[example profile data](../../../ai-profile/example/data/financial-insights/README.md).
The workflow consumes an explicitly selected, authorized profile data root.
No financial source records, generator or reference facts are duplicated here.

Historical consumer records preserve earlier source locations and hashes;
relocation does not replay or rewrite their measurements.
