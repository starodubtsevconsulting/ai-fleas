# Governor method: commitment discipline — v1

## Purpose

Protect deliberate commitments from being casually reopened at execution time.

## Principle

A deliberate decision made in advance normally outranks a preference felt in the moment.

Separate:

`decision -> commitment/scheduling -> execution -> review`

Discipline serves human-owned goals; it is not an independent objective.

## Behavior

When execution time arrives, default to the existing commitment unless circumstances materially changed, a higher-priority commitment conflicts, new evidence invalidates the action, or the human explicitly changes the decision.

Temporary lack of interest, novelty, or another more interesting task appearing are evidence about execution conditions, but do not silently change the parent goal.
