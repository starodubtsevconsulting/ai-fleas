# Personal Governor method: Measurable progress review — v1

## Purpose

Govern progress by comparing observable state against human-owned goals without confusing activity with success.

The Governor uses a short planning horizon while preserving long-term direction. It does not require a detailed multi-year implementation plan.

## Model

Use this hierarchy when useful:

`direction -> goal -> current stage -> checkpoint outcome -> evidence -> next action`

A goal may have known broad stages while the implementation path remains uncertain. Stage names are goal-specific.

## Success

Success means demonstrable movement toward a human-owned goal while respecting the configured strategy and sustainability constraints.

Progress should be supported by observable evidence whenever practical. Evidence does not need to be numeric. Examples include a completed deliverable, validated assumption, external response, working system, reduced cost or complexity, stage transition, corrected mistake, or other material state change.

Activity alone is not evidence of progress.

A delay or mistake is not automatically failure. Record it, correct course when appropriate, and evaluate whether the resulting state is closer to the goal.

## Checkpoints

Evaluate a goal against its current stage rather than only its final outcome.

A goal that ultimately requires paying clients, for example, may currently be in preparation or validation. Client count is not yet the primary evidence if the offer is not ready. The useful question is whether the current stage materially advanced toward the next stage.

Checkpoints should define the evidence expected by a useful review horizon. Prefer bounded, achievable outcomes over speculative long-range implementation plans.

## Review cadence

### Daily: course correction

Use the existing planning/one-on-one interaction to ask:

- What materially changed since the previous review?
- For each active priority, are we closer, unchanged, or farther from the current checkpoint?
- What evidence supports that assessment?
- Did new work create avoidable complexity or displace a current commitment?
- What is the smallest useful next action that can materially advance the current checkpoint?

Daily review should remain lightweight.

### Weekly: trend review

Compare the current state with the previous week:

- what became real that was not real before;
- which goals/stages advanced, stalled, or moved backward;
- what was delivered, learned, simplified, or corrected;
- whether the configured strategy and sustainability constraints were respected;
- whether the next week's approach should continue or change.

Do not overreact to one bad day. Evaluate the trend.

### Monthly: outcome and stage review

Compare the month with its intended checkpoint outcomes:

- achieved, partially achieved, unchanged, or invalidated by new evidence;
- whether the current stage should advance, continue, change, or be deliberately abandoned;
- what small number of checkpoint outcomes should govern the next month.

## Course stability

New ideas are evidence or candidates, not automatic commitments.

Prefer continuing the current course until a checkpoint, material external evidence, changed constraint, or explicit human decision justifies changing it. Capture useful ideas without allowing them to silently replace current priorities.

## Measurement

Use the smallest useful measurement. Prefer direct evidence over proxy metrics.

A valid assessment may be qualitative when grounded in observable state:

- closer;
- unchanged;
- farther.

When a numeric metric is meaningful, use it. Do not invent universal KPIs for goals whose useful evidence is non-numeric.

## Relationship to tasks

Tasks are implementation details. The Governor governs whether execution changed the state of a goal.

Completing many tasks without advancing the current checkpoint is not success by itself.
