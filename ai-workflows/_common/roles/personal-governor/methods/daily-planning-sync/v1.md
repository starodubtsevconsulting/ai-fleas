# Personal Governor method: Daily planning sync — v1

## Purpose

Provide a lightweight daily planning/reconciliation method for the Personal Governor.

The session connects yesterday's evidence, today's capacity and commitments, and the calendar before discretionary work expands. It is a governance checkpoint, not a generic status meeting and not an invitation to spend the morning planning instead of executing.

## Default timing

Prefer the first practical planning window of the day, before substantial discretionary work.

"Morning" is a useful default, not a universal rule. Profiles may configure another stable trigger when work schedules, family obligations, sleep schedules, shifts, or other constraints make morning inappropriate.

The important property is **plan before the day's allocation becomes accidental**.

## Inputs

Retrieve only what is useful:

- active human-owned goals and current strategy;
- yesterday's material activity/evidence and unfinished commitments;
- today's calendar and deadlines;
- relevant capacity/recovery evidence when authorized and useful;
- waiting dependencies, external responses, or new opportunities;
- current operational task state when needed.

## Procedure

### 1. Reconcile yesterday

Ask/establish:

- What materially happened?
- What was completed, missed, moved, or unexpectedly discovered?
- What evidence should be preserved?
- Did any result change an assumption, opportunity, goal, or current allocation?
- Is there unfinished work that should deliberately carry forward?

Do not reconstruct every minute of the previous day. Preserve strategically useful evidence.

### 2. Observe today

Check:

- fixed calendar commitments;
- deadlines/prerequisites;
- available capacity when relevant;
- important environmental constraints;
- newly arrived information that changes the plan.

### 3. Select the day

Choose a small set of outcomes that deserve attention.

Prefer:
- already-chosen commitments over novelty;
- work aligned with active goals;
- bounded closure where it unlocks something important;
- explicit recovery/exercise when it protects sustainable execution;
- leaving unscheduled capacity rather than filling every minute.

### 4. Reconcile the calendar

Use the calendar as the operational commitment surface.

- preserve externally fixed events;
- create/move a small number of meaningful focus blocks when authorized;
- remove obsolete Governor-created follow-up blocks when their parent event moves/cancels;
- include recovery/exercise or preparation blocks when they are genuine commitments;
- do not turn the calendar into a complete task database.

Follow the Personal Governor calendar-governance policy.

### 5. Record

Persist only durable outputs:

- material retrospective evidence belongs to the relevant day;
- new durable decisions/goals/resources follow permanent-memory semantics;
- current schedule remains authoritative in the calendar;
- task state remains in the configured task tracker;
- avoid copying the same full plan into every system.

## Output

A useful daily sync should normally end with a compact view of:

- yesterday: material evidence/carry-forward;
- today: fixed commitments;
- today's 1–3 meaningful outcomes or bounded work blocks;
- recovery/capacity constraint when material;
- deliberate deferrals;
- next review trigger if needed.

## Time-box and anti-patterns

The sync should be bounded. A profile may configure a duration; do not prescribe a universal number.

Avoid:

- spending the best working period endlessly reorganizing the day;
- re-deciding durable strategy every morning;
- filling every free calendar slot;
- converting every idea mentioned during planning into a task;
- silently carrying missed commitments forever;
- treating planning completion as progress on the underlying work.

If planning repeatedly consumes disproportionate time, reduce the method to the minimum reconciliation necessary for execution.

## Relationship to weekly review

Daily sync answers: **what happened, what matters today, and what needs reconciliation now?**

Weekly review answers: **is the larger allocation still working, what patterns emerged, and should strategy/commitments change?**

Do not force strategic reconsideration into the daily loop when no meaningful evidence changed.

## Evidence lifecycle

The method participates in the Governor evidence loop:

`yesterday evidence -> morning reconciliation -> today's commitments -> execution -> resulting evidence -> next reconciliation`

The loop should make missed work, unexpected discoveries, and real-world outcomes visible without requiring the Governor to replay full conversation history.
