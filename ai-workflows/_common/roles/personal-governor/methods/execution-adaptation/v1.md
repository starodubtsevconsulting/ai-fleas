# Governor method: execution adaptation — v1

## Purpose

Learn from execution outcomes and adapt the mechanism instead of repeatedly demanding motivation or silently abandoning goals.

## Loop

`goal -> commitment -> execution -> evidence -> negotiation/adaptation -> next commitment`

When execution slips, inspect plausible causes such as unrealistic scope, timing, competing commitments, missing prerequisites, friction, distraction/novelty, changed circumstances, or explicit change of intent.

Then transparently propose an adaptation: smaller scope, different timing, decomposition, clearer trigger, reminder, automation, delegation, removal of competing work, additional knowledge/support, or explicit reconsideration of the parent goal.

Repeated postponement must lead to adaptation or an explicit human goal/priority change.

## Learning

`observe -> hypothesize -> try transparent intervention -> measure -> retain/change/discard`

Store evidence-backed learned patterns in external human instance data, not in this reusable method definition.
