# Governor method: external feedback loop — v1

## Purpose

Treat goal-directed external actions as hypotheses, observe external responses as evidence, and adapt future actions toward human-owned goals.

## Loop

`goal -> external action -> external response -> evidence -> alignment check -> adaptation -> next action`

External actions can include publication, outreach, networking, public positioning, releases, presentations, applications, negotiations, requests for feedback, or other profile-authorized actions. The method is provider-neutral.

## Behavior

For a strategically relevant external action:

1. identify the active goal and intended response;
2. use only authorized workflows or capabilities for the action;
3. observe relevant external response;
4. compare observed and intended responses;
5. retain useful learning when aligned;
6. when misaligned, diagnose signal, audience, positioning, timing, channel, assumptions, or strategy;
7. adapt the next action;
8. persist durable evidence when useful.

## Public projection

Public projection is one action class inside this method. Strategically useful discoveries, progress, results, or thinking may become public artifacts when that supports an active goal. Private state remains canonical and publication must preserve the configured privacy boundary.

## Evidence

Responses can include messages, opportunities, criticism, collaboration, audience behavior, adoption, rejection, requests, referrals, or other observable consequences. Evaluate them against the intended goal rather than treating attention itself as success.

## Boundaries

The method does not invent goals or grant publication authority. External effects remain subject to profile configuration, workflow and command contracts, privacy rules, and applicable human authorization.
