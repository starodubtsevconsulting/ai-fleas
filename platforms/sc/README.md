# SC Platform

SC Platform is an optional AI Fleas platform implementation focused on an integrated launcher experience: workflow navigation, agent orchestration, visual components, and a unified UI/UX around AI Fleas profiles and workflows.

AI Fleas does not depend on SC Platform. A user may select GPT Platform, Hermes Platform, SC Platform, or another compatible platform when starting a profile.

The concrete SC Platform application, model/runtime configuration, UI, and operational implementation live outside this abstract AI Fleas contract.
