# Example Financial Insights memory project

The example profile selects this placeholder folder project for Financial Insights.
Its configured path does not grant access to real records or authorize durable
changes. Follow the selected profile's storage and publication policy.

The [fictional business-context map](../../../data/financial-insights/business-context.md)
illustrates activities, income origins, service partners, accounts and money
routes. Its invented human confirmations are explicitly attributed and separate
from unverified illustrative expectations. Neither establishes a fact about the
benchmark fixtures or overrides current source evidence.

Use the map to choose what evidence to inspect. Verify identities, ownership,
currency, property and dates before applying an expectation; record unresolved
differences in `reports/YYYY/_common/qN/summary.md`. Keep sources and validated
adjacent CSV/JSON under `reports/YYYY/<business>/qN/{in,out,statements}` and exclude
underscore folders from ordinary intake. The
[record organization flow](../../../../../ai-workflows/financial-insights/flows/record-organization.flow.md)
defines the applicable summary, intake and reserved-folder rules.
